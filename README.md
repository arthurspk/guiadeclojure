## :dart: O guia para alavancar a sua carreira

> Clojure é um Lisp moderno que roda na JVM (e também compila para JavaScript, via ClojureScript), com imutabilidade por padrão e um ciclo de desenvolvimento interativo pelo REPL que muda a forma como você escreve e depura código. É a linguagem por trás de sistemas críticos de empresas como Nubank, Walmart e CircleCI — no Brasil, o próprio Nubank é um dos maiores usuários de Clojure e Datomic do mundo. Este guia reúne documentação, ferramentas, livros, comunidades e projetos práticos para quem já programa (Java, JavaScript, Python) e quer experimentar programação funcional de verdade, ou para quem busca uma vaga em empresas que usam a linguagem. É um nicho pequeno, mas com uma comunidade internacional muito ativa e um ecossistema de ferramentas surpreendentemente maduro — e cada link abaixo foi verificado na data da última revisão.

## 🗺️ Roadmap
Clojure não tem um roadmap visual oficial como outras linguagens (não há entrada mantida em roadmap.sh), então a comunidade se orienta por três materiais de referência:
- [Clojure for the Brave and True](https://www.braveclojure.com) — o livro/site gratuito mais indicado como ponto de entrada: cobre do "Hello World" a macros e concorrência, com humor e exercícios.
- [Practicalli Clojure](https://practical.li/clojure/) — livro aberto e continuamente atualizado (Jr0/Practicalli) com trilha estruturada: REPL, sintaxe, testes, deploy, arquitetura.
- [clojure.org — Guides](https://clojure.org/community/resources) — página oficial de recursos, mantida pela equipe da linguagem, com links organizados por tema.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Instalação e REPL** — Clojure CLI (`deps.edn`) via Homebrew/instalador oficial, e um editor com REPL integrado (Calva no VS Code, Cursive no IntelliJ ou CIDER no Emacs).
2. **Fundamentos** — sintaxe de s-expressions, `def`/`let`, funções, imutabilidade, sequências (`map`, `filter`, `reduce`).
3. **Estruturas de dados** — listas, vetores, mapas, sets, keywords, desestruturação (*destructuring*).
4. **Desenvolvimento no REPL** — avaliar expressão por expressão dentro do editor, sem recompilar o projeto inteiro a cada mudança.
5. **Funcional intermediário** — namespaces, protocolos e multimétodos, recursão com `recur`, sequências preguiçosas (*lazy seqs*).
6. **Concorrência e estado** — atoms, refs, agents e `core.async` para canais e processos concorrentes.
7. **Qualidade** — testes com `clojure.test`, lint com clj-kondo, gerenciamento de dependências com `deps.edn` ou Leiningen.
8. **Especialização** — web (Ring, Reitit, Pedestal), dados (Datomic, XTDB), frontend (ClojureScript com re-frame/Reagent) ou scripting (Babashka).

## 🚀 Por onde começar
1. **Instale a Clojure CLI** seguindo o [guia oficial de instalação](https://clojure.org/guides/getting_started) (macOS via Homebrew, Linux via script, Windows via scoop/instalador).
2. **Experimente sem instalar nada** no [try Clojure](https://tryclojure.org/) (REPL interativo no navegador) ou no [Replit](https://replit.com/languages/clojure).
3. **Leia o livro gratuito** [Clojure for the Brave and True](https://www.braveclojure.com) — o material mais recomendado pela comunidade para começar do zero.
4. **Configure seu editor com REPL:** [Calva (VS Code)](https://calva.io/), [Cursive (IntelliJ)](https://cursive-ide.com/) ou [CIDER (Emacs)](https://cider.mx/) — o REPL conectado ao editor é o diferencial de produtividade da linguagem.
5. **Pratique com exercícios guiados:** os [Clojure Koans](https://github.com/functional-koans/clojure-koans) ensinam a sintaxe corrigindo testes que falham, um de cada vez.
6. **Consulte a referência sempre que precisar:** o [cheatsheet oficial](https://clojure.org/api/cheatsheet) e o [ClojureDocs](https://clojuredocs.org/) (exemplos da comunidade para cada função).
7. **Aprofunde-se no livro aberto** [Practicalli Clojure](https://practical.li/clojure/), que cobre testes, build, deploy e arquitetura de aplicações reais.
8. **Construa um projeto pequeno:** resolva os primeiros dias do [Advent of Code](https://adventofcode.com/) ou os katas do [Codewars em Clojure](https://www.codewars.com/kata/search/clojure).

Seu primeiro projeto em 30 segundos:

```bash
brew install clojure/tools/clojure   # macOS; para Linux/Windows veja o guia oficial
mkdir ola-clojure && cd ola-clojure
```

```clojure
;; ola.clj
(defn saudacao [nome]
  (str "Olá, " nome "!"))

(println (saudacao "Guia Dev Brasil"))
```

```bash
clj -M ola.clj                       # executa com a Clojure CLI (sobe a JVM)
bb ola.clj                           # alternativa instantânea: Babashka, sem aquecimento da JVM
```

## 🛠️ Ferramentas
### Instalar, gerenciar e escrever código
- [Clojure CLI e deps.edn (oficial)](https://clojure.org/guides/deps_and_cli) — Ferramenta oficial de linha de comando e o formato padrão de gerenciamento de dependências.
- [Leiningen](https://leiningen.org/) — O gerenciador de build e dependências mais tradicional do ecossistema, anterior à Clojure CLI e ainda muito usado.
- [Babashka](https://babashka.org/) — Interpretador de Clojure para scripting, com inicialização instantânea (sem a JVM) — ideal para substituir scripts em bash/Python.
- [Rebel Readline](https://github.com/bhauman/rebel-readline) — REPL de terminal com destaque de sintaxe, indentação automática e melhor experiência de digitação.
- [nREPL](https://nrepl.org/) — Protocolo e servidor de REPL usado por praticamente todos os editores para conectar ao Clojure em execução.
- [Portal](https://github.com/djblue/portal) — Visualizador de dados que abre em uma aba separada, útil para inspecionar estruturas de dados grandes durante o desenvolvimento.
- [clj-kondo](https://github.com/clj-kondo/clj-kondo) — Linter estático rápido para Clojure/ClojureScript, com integração em todos os editores principais.

### Editores
- [Calva (VS Code)](https://calva.io/) — Extensão para VS Code com REPL integrado, avaliação inline e depurador — a opção mais popular para quem já usa VS Code.

## 🤖 IA na prática
Clojure tem uma característica que combina especialmente bem com assistentes de IA: o **REPL**. Como cada expressão pode ser avaliada e inspecionada isoladamente, é possível pedir uma sugestão à IA e confirmar o resultado na hora, sem esperar recompilar o projeto inteiro — o mesmo ciclo rápido que já é a cultura da linguagem desde antes da IA generativa existir.

**Para aprender**
- Cole uma stack trace do Clojure (geralmente longa, com várias camadas de `clojure.lang`) e peça para a IA apontar a linha do **seu** código onde o erro realmente começou.
- Peça para reescrever um trecho imperativo (loops com estado mutável) de forma **idiomática**: `map`/`filter`/`reduce`, `->`/`->>` (threading macros) e desestruturação.
- Peça exercícios curtos sobre o tópico que está estudando (ex.: "5 exercícios sobre lazy sequences com gabarito") e resolva no REPL antes de conferir.
- Use a IA para explicar macros: peça para expandir mentalmente uma macro passo a passo e depois confira com `(macroexpand '(...))` no REPL.

**Para trabalhar**
- [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) e [Claude Code](https://code.claude.com/docs/en/overview) funcionam com Clojure como com qualquer linguagem no editor — a diferença é que, com REPL conectado (Calva/CIDER/Cursive), você pode pedir para a IA gerar uma função e avaliá-la imediatamente, sem sair do fluxo.
- [clojure-mcp (Bruce Hauman)](https://github.com/bhauman/clojure-mcp) — Servidor MCP (Model Context Protocol) que dá a agentes de IA acesso direto a um REPL Clojure real: o agente escreve, avalia e corrige código no mesmo processo em execução, em vez de só gerar texto. Criado em 2025 pelo autor do Figwheel.
- [Model Context Protocol — documentação oficial](https://modelcontextprotocol.io/docs/2026-07-28/sdk) — Protocolo aberto (Anthropic) que o clojure-mcp implementa; útil para entender como conectar qualquer agente de IA a ferramentas locais.
- [openai-clojure (wkok)](https://github.com/wkok/openai-clojure) — Cliente Clojure para a API da OpenAI, gerado a partir da especificação oficial — útil para chamar modelos de IA diretamente do seu código Clojure.
- Sem SDK oficial de Clojure para Claude ou OpenAI, o caminho mais comum é chamar a API HTTP diretamente com [clj-http](https://github.com/dakrone/clj-http) ou [hato](https://github.com/gnarroway/hato) — poucas linhas de código, já que as APIs são JSON sobre HTTP.

**Limites e boas práticas**
- IA erra mais em Clojure do que em linguagens mais populares (menos código de treinamento disponível): confira sempre a assinatura de funções no [ClojureDocs](https://clojuredocs.org/) antes de aceitar uma sugestão.
- Desconfie de código que usa `eval`, `read-string` sobre entrada não confiável ou desabilita a imutabilidade sem necessidade (`volatile!`/`atom` usados como variável global) — são padrões que a IA às vezes sugere por vir de outras linguagens.
- Macros geradas por IA merecem atenção redobrada: teste com `macroexpand` antes de confiar que fazem o que parecem fazer.
- Não cole dados de produção, credenciais ou código proprietário em ferramentas sem a política da sua empresa — vale para Clojure como para qualquer linguagem.

## 💼 Carreira e vagas
Clojure é uma linguagem de nicho no mercado brasileiro: poucas vagas, mas concentradas em empresas que a adotaram deliberadamente pela produtividade e robustez que ela oferece — o exemplo mais visível é o **Nubank**, que construiu boa parte de seu backend em Clojure e é dono do Datomic. Não existe, até esta revisão, um agregador de vagas de Clojure específico para o Brasil — a orientação é acompanhar diretamente as empresas que usam a linguagem e os quadros de vagas gerais de tecnologia.
- [Empresas que usam Clojure (oficial, clojure.org)](https://clojure.org/community/companies) — Lista oficial e curada, incluindo o Nubank e outras empresas com vagas ocasionais para a linguagem.

- [Stack Overflow Developer Survey 2024](https://survey.stackoverflow.co/2024/technology) — Edição anterior da mesma pesquisa, útil para comparar tendência de uso e satisfação ano a ano.
